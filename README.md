# OpenApolloV2
Repository for OpenApollo V2

The OpenApollo Project strives to lower the bar-of-entry for beginners to rocketry and aviation!
One of the most difficult parts of rocket design is the electronics, as it has to be foolproof with redundancy and safety measures.
This is achieved by open-sourcing a pre-built controller, with pre-made code (coming soon lol) for low-level control, which is the other
difficult part, which can then be controlled with high-level, easy-to-write code on a Raspberry Pi CM5 module.

OpenApollo V2 is a step-up from OpenApollo V1 with better system architecture, smaller size, and faster feedback loops.
